# Syfer Password Manager 🔐

Syfer is a web-based password manager designed to securely store and manage user credentials.

## 📌 Features
- User registration and login (authentication)
- Store passwords for different websites
- Encrypt sensitive data (AES encryption)
- View, edit, and delete saved passwords
- Organize passwords by category
- Search and filter stored passwords

## 🛠️ Technologies Used
- Frontend: HTML, CSS, React
- Backend: Node.js, Express
- Database: MySQL
- Security: AES Encryption

## 🗄️ Database
The database schema is provided in the `schema.sql` file.

It includes:
- `users` table (for authentication)
- `vault_entries` table (for storing encrypted passwords)

## 👥 Team Roles
- Database Architect: Designed database schema and queries
- Backend Developer: Built server and API
- Frontend Developer: Designed user interface
- Security Specialist: Implemented encryption and security features

## 🚀 Project Goal
To create a secure and user-friendly password manager similar to LastPass or 1Password for educational purposes.
